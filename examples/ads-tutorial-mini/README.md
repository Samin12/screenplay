# ads-tutorial-mini

A 35-second tutorial edit that uses every "tutorial" feature of the engine in one small file:

- `chapters.style: path` with two levels, three tips, labels, groups and a locked tip ahead
- all three layouts (`panel`, `full`, `him`) with hard-cut switches between them
- a `chip` and a `steps` strip that stay up over the scenes, both recreated windows and the presenter
- a recreated Finder window and a recreated Claude window (light, stamped "Recreated", fictional data)
  that types a prompt and gets a plan back

Nothing in it is real footage. The presenter is two flat shapes on a gradient and the "voice" is a
tone burst per word over low room noise, both generated by a script. `words.out.json` is hand written.

```bash
node examples/ads-tutorial-mini/make-media.mjs          # writes aroll.mp4 and media/*.png (needs ffmpeg)
node cli/screenplay.ts check examples/ads-tutorial-mini
node cli/screenplay.ts render examples/ads-tutorial-mini --preview
node cli/screenplay.ts sheet examples/ads-tutorial-mini --every 1s
```

Files: `edit.yaml` (the edit), `words.out.json` and `aroll.json` (the timing the edit anchors to),
`make-media.mjs` (the placeholder media). The media itself is not committed.
